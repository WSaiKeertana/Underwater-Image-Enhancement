# 🌊 Underwater Image Enhancement

> A Computer Vision project implementing **CLAHE** and **FUnIE-GAN** to improve underwater image quality using both classical image processing and deep learning techniques.

---

## 📌 Overview

Underwater images often suffer from low contrast, color distortion, and reduced visibility due to light absorption and scattering. This project explores two different approaches for underwater image enhancement and compares their effectiveness.

The repository contains:

- 📈 CLAHE (Contrast Limited Adaptive Histogram Equalization)
- 🤖 FUnIE-GAN (Fast Underwater Image Enhancement GAN)

---

## ✨ Features

- Underwater image preprocessing
- Classical image enhancement using CLAHE
- Deep learning-based enhancement using FUnIE-GAN
- Visual comparison of enhanced images
- Image quality evaluation

## 📖 Enhancement Methods

### 🔹 CLAHE

Contrast Limited Adaptive Histogram Equalization (CLAHE) enhances local image contrast while limiting noise amplification. It is particularly effective for improving visibility in underwater environments.

---

### 🔹 FUnIE-GAN

FUnIE-GAN is a lightweight Generative Adversarial Network designed specifically for real-time underwater image enhancement. It improves color correction, contrast, and overall visual quality.

---
