# Underwater-Image-Enhancement
Developed an underwater image enhancement pipeline implementing both classical image enhancement and deep learning-based techniques to improve underwater image quality. The methods are evaluated using objective image quality metrics for comparison.

## Features

- Underwater image preprocessing
- Classical image enhancement
- Deep learning-based image enhancement
- Image quality evaluation

## Technologies Used

- Python
- OpenCV
- TensorFlow
- Keras
- NumPy
- Google Colab

## Repository Structure

```
├── README.md
├── Method1.ipynb
├── Method2.ipynb
├── images/
└── outputs/
```
